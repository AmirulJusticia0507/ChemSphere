# Technical Skills & Requirements

Dokumen ini memuat daftar kompetensi teknis dan _stack requirement_ yang digunakan dalam pengembangan sistem ini.
---

## 1. Core Competencies

- **Frontend Engineering**

  - PWA Development dengan Vue.js 3 (Reactivity, Lifecycle Hooks, Composables).
  - State Management terpusat menggunakan Pinia.
  - Styling responsif dan modern dengan Tailwind CSS.
  - Integration REST API menggunakan Axios.

- **Backend Engineering**

  - RESTful API design dengan Node.js & Express.js.
  - Middleware pattern (Auth Guard, Error Handler, Request Validator).
  - Security best practices (Cors, Helmet, Rate Limiting, Hashing Passwords dengan bcrypt).

- **Database Administration**

  - Relational Database Design (Normalized 3NF).
  - PostgreSQL indexing, transactions, dan relational constraints.
  - Database Migration & Seeding.

---

## 2. Developer Tools & Workflow

- **Version Control:** Git & GitHub / GitLab (Feature Branch Workflow)
- **API Testing:** Postman / Insomnia
- **Containerization (Optional):** Docker & Docker Compose
